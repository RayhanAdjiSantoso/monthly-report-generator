▼
1
Download report Iklan Toko & Iklan Produk
Dari dashboard Shopee Seller Center, buka menu Iklan Saya dan download laporan untuk masing-masing jenis iklan (Iklan Toko dan Iklan Produk), untuk bulan lalu dan bulan ini — total 4 file.
2
Catat Total Omzet Toko dari dashboard
Buka halaman Performa Toko di Shopee Seller Center dan pilih status 'Pesanan Dibuat'. Salin angka Total Omzet untuk bulan lalu dan bulan ini — angka ini tidak tersedia di file CSV iklan sehingga perlu diisi manual.
3
Upload file & generate laporan
Isi kolom Total Omzet, upload keempat file CSV, lalu klik Generate Laporan.
